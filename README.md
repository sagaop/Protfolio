# zarn: portfolio

A static portfolio site (no build step, no dependencies).

## Files
- `index.html`: page markup
- `style.css`: styles
- `script.js`: animated beams background, counters, interactions

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy on GitHub Pages
1. Push these files to the root of a repo.
2. Repo **Settings → Pages → Deploy from a branch → `main` / root**.
3. Your site goes live at `https://<username>.github.io/<repo>/`.

Works the same on Vercel or Netlify (drag and drop the folder).
